1. Zero-Lag Studio Workspace

CANVAS 01

Opens with a clean slate. Search or pick any installed Odoo module (e.g. sale, fleet, account) from the sidebar without freezing your browser.

2. Structural Architecture Graph

GRAPH 02

Cytoscape-powered high-performance graph with multiple layout algorithms (Hierarchy, Flow, Organic). Visualizes model inheritance, relational field links, and foreign module bridges.

3. Interactive ERD Schema Cards

SCHEMA 03

Visual database schema table cards with color-coded badges for relational (Many2one, One2many, Many2many), numeric, computed, and selection fields with drag & zoom.

4. BFS Relational Pathfinder

PATHFINDER 04

Calculates the shortest relational route between any two database models and generates 1-click ORM dot-notation code (e.g. partner_id.currency_id.symbol).

5. Architecture Health & Diagnostics

DIAGNOSTICS 05

Explore full database schemas, circular dependencies, isolated orphan models, degree centrality, and model inheritance hierarchies in one unified dashboard.

6. High-Resolution ERD Table Card Export

EXPORT 06

Export clean, presentation-ready PNG diagrams of your database tables or automatically partition large modules into clustered ZIP bundles with a manifest index.

7. High-Resolution Architecture Graph Export

EXPORT 07

Download full-vector Cytoscape graph diagrams with automatic metadata watermarking, perfect for technical architecture documentation, sprint planning, and client handoffs.

Quick Start (3 Simple Steps)

STEP 01 // INSTALL

Place ormgraph_odoo in your addons path, update apps list, and click Install.

STEP 02 // LAUNCH

Open ORMGraph Studio from the main app switcher or the smart button on any Technical Model form.

STEP 03 // EXPLORE

Select any module to inspect graphs, review ERDs, trace paths, and export high-res PNG/ZIP bundles.
